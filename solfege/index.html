Listen to a start note and then another note. Which note was the second one?

Each round plays the start note, then a second note near it. Answer by pressing the second note on the keyboard, by choosing the interval between the two, or by typing its name. Get it right and the next round starts.

The settings below choose the start note, how far away the second note can be, and the sound.

the start note. Pressing a key plays it and answers with that exact note.

  • A note: c d e f g a b with # or b, Dutch fis, bes, es, as, or fixed do: do re mi fa sol la si. Any octave counts. To be exact, add one: d4, eb5 (middle C is c4), or LilyPond style d', bes,.
  • An interval from the start note: 2 is a major second, 2- a minor second, 4+ or 5- the tritone, 8 an octave. For 1, 4, 5 and 8, + and - mean augmented and diminished; for the others, - is minor, -- diminished and + augmented.
  • A direction: put + or - in front for up or down, so -3- is a minor third down. Without one, either direction counts.
  • Commands: an empty answer or r plays both notes again, p the second note, s shows the answer and n goes on to the next note.
